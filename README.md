# Neimark Market — Telegram Payment Bot & Shop 🛍️

This project was developed during the **PROF IT Hackathon** (January 2025). We created a comprehensive ecosystem for an IT campus to increase student engagement.

## 📋 Project Overview
The goal was to create a Telegram Web App where participants can earn internal currency for activities and spend it on branded merchandise (merch).

### Key Features:
- **User Side:** Registration, news feed, profile management, and a shop catalog.
- **Admin Side:** Order management, user database, and manual balance updates.
- **Visuals:** Full custom UI/UX design following the "Neimark" brand identity.

## 🎨 My Role: UI/UX Designer & Product Lead
I was responsible for the visual strategy and interface design:
- Developed the **Brand Identity** (logo, color palette, typography).
- Created **High-fidelity Prototypes** in Figma.
- Designed the **User Journey** for the Telegram Web App interface.
- Coordinated the team to ensure the design was accurately implemented in the frontend.

## 🛠 Tech Stack (Team)
- **Design:** Figma, Pinterest
- **Backend:** Python (Django, DRF), PostgreSQL, Nginx
- **Frontend:** HTML, CSS, JavaScript (Telegram Web App API)
